Multiple Linear Regression Equation

The predictive model computes expected Final Exam Marks (\(\hat{y}\)) as a weighted linear combination of input features:

\[\hat{y} = \beta_0 + \sum_{i=1}^{5} \beta_i \cdot x_i\]

Target Variable:

  • \(\hat{y}\): Predicted Final Exam Marks (bounded 0 - 100)

Input Features (\(x_i\)):

  1. \(x_1\): Attendance Percentage (%)
  2. \(x_2\): Weekly Study Hours
  3. \(x_3\): Previous Semester Marks (%)
  4. \(x_4\): Assignment Marks (%)
  5. \(x_5\): Internal Exam Marks (%)
Input features are standardized using StandardScaler before fitting model coefficients.
